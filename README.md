# The Grove

A Unity-based environmental ecosystem and interactive weather demo built around Distant Lands COZY content.

## What this project does

The Grove is a Unity project that combines dynamic ecosystem simulation, stylized weather, and interactive spawning controls. It uses local Distant Lands COZY modules to drive weather, atmosphere, water, and environment behavior while exposing gameplay-style UI for spawning species, toggling weather, and viewing ecosystem stats.

## Why this project is useful

- Demonstrates a polished Unity ecosystem with stylized weather and dynamic environment systems
- Includes a title flow and an interactive main scene with spawn controls, weather buttons, and UI overlays
- Integrates local COZY packages for weather, horizon, smoke/clouds, audio, and habits
- Provides a Unity 6.0.35f1-compatible project structure with source scripts, scenes, and package configuration

## Key features

- `Assets/Scenes/Title.unity` launch scene with `TitleScreenManager` to open the main experience
- `Assets/Scenes/Main.unity` gameplay scene with dynamic weather, spawning, and ecosystem UI
- Interactive UI components for species selection, token display, and animal overview
- Weather control using COZY `WeatherProfile` assets and `InteractionManager.ToggleSummonWeatherMode`
- Procedural environment systems, fertility/moisture tracking, and water source updates
- Camera and input systems supporting focused and RTS-style behavior

## Getting started

### Prerequisites

- Unity Editor 6.0.35f1
- Universal Render Pipeline (URP) support enabled by the project
- Unity Input System available in the package manifest

### Open the project

1. Clone the repository:

```bash
git clone <repo-url>
cd The-Grove
```

2. Open the project in Unity Hub using the repository root.
3. In the Editor, open `Assets/Scenes/Title.unity` and press Play.

### Run the project

- Start from `Assets/Scenes/Title.unity`
- Use the title screen buttons to load `Main` scene
- In the main scene, interact with spawning controls, weather buttons, and ecosystem UI

## Project structure

- `Assets/Scenes/` — core Unity scenes, including `Title.unity` and `Main.unity`
- `Assets/Scripts/` — gameplay, UI, camera, controls, ecosystem, and environment scripts
- `Packages/manifest.json` — Unity package dependencies for the project
- `Packages/packages-lock.json` — package lock file for local Distant Lands COZY modules
- `ProjectSettings/ProjectVersion.txt` — required Unity editor version for this project
- `The Grove.sln` / `The-Grove.sln` — Visual Studio solution files for editing C# scripts

## Dependencies

The repository uses Unity package dependencies defined in `Packages/manifest.json`, including:

- `com.unity.inputsystem`
- `com.unity.render-pipelines.universal`
- `com.unity.visualscripting`
- `com.unity.visualeffectgraph`
- `com.unity.timeline`

It also contains local COZY package modules under `Packages/com.distantlands.cozy.*` that are referenced by the project.

## Notes

- `Library/`, `obj/`, `Logs/`, and `UserSettings/` are generated by Unity and should not be edited or committed.
- `Assets/Distant Lands/COZY Pro/` contains COZY-related asset and editor integrations used by the scene.
